# Dashboard Climático Brasileiro

## Sobre o Projeto

Este projeto foi desenvolvido para a disciplina de Linguagem de Programação – Análise e Visualização de Dados com Python.

O objetivo é analisar dados climáticos de diferentes regiões do Brasil entre 2015 e 2025, identificando padrões de temperatura, precipitação, umidade e eventos extremos.

## Tecnologias Utilizadas

* Python
* Pandas
* Matplotlib
* Seaborn
* Streamlit
* GitHub

## Funcionalidades

* Filtros por ano, região e UF
* KPIs dinâmicos
* Análise temporal
* Visualizações comparativas
* Dashboard interativo

## Estrutura do Projeto

* app.py → Dashboard Streamlit
* simulacao_clima_brasil.csv → Base de dados
* notebooks/ → Notebook de análise
* imagens/ → Imagens do projeto
* database/ → Estrutura reservada para banco de dados
